# Security and Vulnerability Reporting

Do not disclose a suspected vulnerability, credential, private endpoint,
customer record, or exploit procedure in a public issue.

Report security concerns privately to **support@kilodrive.com** with:

- a concise description of the affected component;
- the observed and expected behavior;
- safe reproduction conditions using non-production data;
- impact and suggested mitigation, if known; and
- a contact method for coordinated follow-up.

Do not access data that is not yours, disrupt service, perform uncontrolled load
testing, bypass authorization, or retain personal information. KiloDrive will
triage reports, preserve evidence, assign severity and ownership, and coordinate
remediation and disclosure based on impact.
