# Official KiloDrive product links

These public destinations connect the architecture documents to the product
information available to customers, Transportation Service Providers and other
readers. The website and consumer Google Play links were checked on
2026-09-30; all three edition 4.0 PDF manuals were published and read back on
2026-10-20. Website pages may present different availability, currency, terms
or language after a reader selects a country. The current
in-app disclosure and country-specific published terms govern a transaction;
this repository does not replace them.

The public PDF readback was verified on 2026-10-20. These guides were generated
from consumer source `1.0.0+238` and schema `2026.10.19.8`. A manual's
publication does not prove the matching store build or every country service
is active.

The Google Play link is for the **consumer** app. The separate System Admin app
has its own restricted distribution and should not be represented as a public
consumer download. A store listing, website button or source package name is
not proof that a particular country, feature, provider or release is active.

## Published build-196 manuals

Edition 3.3 was read back on 2026-10-06 for consumer `1.0.0+196` and schema
`2026.10.05.2`. That is historical publication evidence, not a link to a
frozen edition or a claim that it certifies the current apps. Use the current
edition 4.0 links above. Transportation Provider now combines driving,
courier and rental guidance; previously shared `/manuals/driver` routes remain
a compatibility path to the combined guide. Account country and native-store
storefront can differ, and an uncertain purchase needs original-operation
recovery. Administrative decisions remain in the separate System Admin app.
