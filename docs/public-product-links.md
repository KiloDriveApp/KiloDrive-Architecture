# Official KiloDrive product links

These public destinations connect the architecture documents to the product
information available to riders, drivers, rental providers and other readers.
The links below were checked against the live website and consumer Google Play
listing on 2026-09-30. Website pages may present different availability,
currency, terms or language after a reader selects a country. The current
in-app disclosure and country-specific published terms govern a transaction;
this repository does not replace them.

| Resource | Official destination | Use |
| --- | --- | --- |
| KiloDrive website | [kilodrive.com](https://kilodrive.com/) | Start with the country-aware public site and select the relevant market. |
| User manuals | [Manual library](https://kilodrive.com/manuals) | Find the current public guides and their downloadable editions. |
| Rider manual | [Rider operations manual](https://kilodrive.com/manuals/rider) | Rider onboarding, trips, wallet, safety and support. |
| Driver manual | [Driver operations manual](https://kilodrive.com/manuals/driver) | Driver readiness, vehicles, bidding, membership and earnings. |
| Rental provider manual | [Rental provider operations manual](https://kilodrive.com/manuals/rental-provider) | Fleet, bookings, handover, finance and support. |
| Contact and support | [Contact KiloDrive](https://kilodrive.com/contact) | Public enquiries; use in-app support for an account-specific case. |
| Product updates | [What's new](https://kilodrive.com/changelog) | User-facing release and change information. |
| Privacy Policy | [Privacy Policy](https://kilodrive.com/privacy) | Public notice about data handling and user choices. |
| Cookie Policy | [Cookie Policy](https://kilodrive.com/cookie-policy) | Website storage, measurement and preferences. |
| Data protection | [Data protection](https://kilodrive.com/data-protection) | Public overview of privacy governance and rights. |
| Terms of Service | [Terms of Service](https://kilodrive.com/terms) | Public contractual terms; review applicable country and service schedules. |
| Legal Center | [Legal Center](https://kilodrive.com/legal) | Find policy versions and related legal notices. |
| Consumer Android app | [KiloDrive on Google Play](https://play.google.com/store/apps/details?id=com.kilodrive.app) | Consumer app listing; store availability can vary by country or account. |

The Google Play link is for the **consumer** app. The separate System Admin app
has its own restricted distribution and should not be represented as a public
consumer download. A store listing, website button or source package name is
not proof that a particular country, feature, provider or release is active.
